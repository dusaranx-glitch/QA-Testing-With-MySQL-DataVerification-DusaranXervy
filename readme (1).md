# Kara David's Wish Note: QAT Toolkit

## Repository Overview

This QAT (Quality Assurance Testing) toolkit documents the functional testing of an AI-generated web application. The repository contains three parts:

- **Part A:** This README file, containing the test case for an AI-generated web application.
- **Part B:** The AI prompt used to create the test web application, named `webapp-generation-prompt.txt`.
- **Part C:** The single-file PHP web application generated by AI, named `test-webapp.php`.

The original source text of the test case is also included in this repository as `textcase.txt`.

### Database Verification Query (Step i)

```sql
USE birthday_wishnote;
SELECT * FROM main_corrupt_politicians;
```

## Defect Summary

- **Defect:** The `Location` value entered in the form is not stored in the database.
- **Affected column:** `Location` in table `main_corrupt_politicians`.
- **Root cause:** The application's `INSERT` statement only includes `FirstName`, `LastName` and `GovPosition`, and omits `Location` from both the SQL string and `bind_param`.
- **Result:** Test case TC-DataEntry-001 is marked **Failed**.

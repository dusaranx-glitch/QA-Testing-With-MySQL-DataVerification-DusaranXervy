Test Case ID: TC-DataEntry-001
Test Case Title: Data Entry - Valid
Test Case Description: Functional Testing of Data Entry page with Backend validation using MySQL queries.
Preconditions: Kara David Birthday Wishnote App is installed locally and MySQL database is pre-populated for comparison. Data entry page is accessed in latest Chrome/Firefox browser.
Test Data: Five (5) valid entries containing First Name, Last Name, Government Position, and Location and within their maximum character limits.
  1. Juan | Dela Cruz | Mayor | Iloilo City
  2. Maria | Santos | Governor | Cebu
  3. Pedro | Reyes | Councilor | Manila
  4. Ana | Garcia | Senator | Davao
  5. Jose | Ramos | Barangay Captain | Bacolod
Test Steps:
a. Verify that the form contains labels in proper order and the text boxes are writable
b. Verify the "Send Wish Note" button.
c. Enter test data on their respective fields
d. On clicking of "Send Wish Note" button, a modal will appear.
e. Verify if the modal contains the same entry as your test data
f. Click the Cancel button
g. Click again on "Send Wish Note" button, and click on "Confirm and Send" button in the modal box.
h. Verify if a successful entry message shows in the Data Entry page.
i. Verify the test data if it shows in the database.

Expected Results:
a. The form contains labels in this order: "Target's First Name", "Target's Last Name", "Target's Government Position", and "Target's Location"; all text boxes are writable
b. The "Send Wish Note" button changes color on hover and is not disabled
c. The respective fields accept data entries of valid test data.
d. A modal titled "Verify Target Data" appears.
e. The modal shows the same First Name, Last Name, Government Position and Location as the test data.
f. The modal closes and nothing is submitted.
g. The form is submitted and the modal closes.
h. The message "Success! The wish note has been sent." appears above the form.
i. All five entries, including Location, are saved in the database. Query used: SELECT * FROM main_corrupt_politicians;

Actual results:
a. The form contains labels in this order: "Target's First Name", "Target's Last Name", "Target's Government Position", and "Target's Location"; all text boxes are writable
b. The "Send Wish Note" button changes color on hover and is not disabled
c. The respective fields accept data entries of valid test data.
d. A modal titled "Verify Target Data" appeared.
e. The modal showed the same entries as the test data.
f. The modal closed and nothing was submitted.
g. The form was submitted and the modal closed.
h. The message "Success! The wish note has been sent." appeared above the form.
i. Query used: SELECT * FROM main_corrupt_politicians; All five rows were saved with FirstName, LastName and GovPosition, but the Location column is NULL in all five rows.

Status: Failed
